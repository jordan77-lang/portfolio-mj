## Overview

Lab Workbook (ITE Mission Archive — Module 1: Atoms, Structure & Bonding) is an interactive chemistry mission workbook. Students open mission file “terminals,” log measurements and calculations, complete related trainings, and export a PDF report for Canvas.

## Source

- Repository: [github.com/jordan77-lang/Labworkbook](https://github.com/jordan77-lang/Labworkbook)

## Features

- Mission-style navigation across acts
- Guided data entry for observations and calculations
- Integrated mission trainings
- PDF export for course submission workflows
- Browser-based — no installation required

## Instructional use

Supports immersive STEM curriculum where lab practice, narrative framing, and submission logistics need to live in one student-facing experience.
