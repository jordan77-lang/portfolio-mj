# Interpreting Frequency Distributions

An interactive training module that teaches learners how to interpret frequency distributions by identifying peaks (modality) and describing shape (symmetry).

## Overview

This training uses a chicken-themed narrative to teach statistical concepts in an engaging way. Learners progress through scaffolded steps with visual examples and interactive practice.

## Pages

- **index.html** - Introduction and learning objectives
- **step1.html** - What is a frequency distribution?
- **step2.html** - Identifying peaks (modality)
- **step3.html** - Describing shape (symmetry)
- **practice.html** - Interactive practice with feedback
- **summary.html** - Key takeaways and review

## Features

- SVG-based interactive charts
- Immediate feedback on practice questions
- Progress tracking header
- Mobile responsive design

## Usage

Open `index.html` in a browser or serve with a local web server.
